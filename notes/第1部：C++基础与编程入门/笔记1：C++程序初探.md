## 1.1：C++程序的基本结构（main函数、预处理器、头文件）

### 1.1.1：最简单的C++程序
```cpp
#include <iostream>
int main()
{
    using namespace std;
    cout << "Hello World !" << endl;
    return 0;
}
```
### 1.1.2：程序的基本结构模块
```cpp
#include <iostream>    //预处理器指令
int main()             //函数头
{                      //函数定义开始
    //语句
    return 0;          //返回语句
}                      //函数定义结束
```
### 1.1.3：main()函数
| 要点 | 说明 |
| :--- | :--- |
| 必须存在 | C++程序必须包含一个名为`main()`的函数 |
| 程序入口 | 程序从`mian()`开始执行 |
| 大小写敏感 | 必须是`main` |
| 标准格式 | `int main()`（推荐），`int main(void)`也可 |
| 返回值 | 返回`int`值给操作系统，0通常表示成功，非0为失败 |
| 隐式返回 | 可省略`return 0`; 编译器会隐式添加（仅适用于`main`） |
| 不推荐 | `void main()`是非标准写法，某些系统不支持 |
### 1.1.4：预处理器（#include）
- 预处理器在编译之前处理以#开头的编译指令
- `#include <iostream>`将`iostream`头文件的内容替换到该位置
- 原始代码文件没有被改变，而是生成一个组合文件供编译器处理
### 1.1.5：头文件
**头文件命名约定**
| 头文件类型 | 命名约定 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| C++旧式 | 以 .h 结尾 | iostream.h | C++ |
| C旧式 | 以 .h 结尾 | math.h | C/C++ |
| C++新式 | 无扩展名 | iostream | C++，支持名称空间 |
| 转换后的C | 前缀c，无扩展名 | cmath | C++，支持名称空间 |

**要点：**
- 使用`cin`/`cout`必须包含 `#include <iostream>`
- 新式头文件（无`.h`）将定义放在`std`空间中

## 1.2：名称空间与cout输出/cin输入

### 1.2.1：名称空间（namespace）
**为什么需要名称空间：**
- 解决大型程序中的命令冲突
- 不同厂商的代码可能使用相同的函数名
- 例如：`Microflop::wanda()`和`Piscine::wanda()`可以同时存在
**std名称空间：**
- C++标准库的所有定义（`cout`、`cin`、`endl`等）都位于`std`名称空间中
- 新式头文件（无`.h`）才使用名称空间
**访问std的四种方式：**
```cpp
//方式1：全部引入（简单，适合小项目）
using namespace std;

//方式2：仅在有需求的函数中引入
void func()
{
    using namespace std;
    cout << "Hello" << endl; 
}

//方式3：只引入特定元素（推荐）
using std::cout;
using std::endl;
using std::cin;

//方式4：每次使用std::前缀（最明确）
std::cout << "Hello" << std::endl;
```
### 1.2.2：cout输出
**基本用法：**
```cpp
cout << "Hello World!";     //输出字符串
cout << endl;               //换行并刷新缓冲区
```
**拼接输出：**
```cpp
//多条语句拼接
cout << "Now you have" << "carrots." << endl;

//同一语句分多行（C++自由格式）
cout << "Now you have "
     << carrots
     << " carrots."
     << endl;
```
**endl与\n的区别**  
| 写法 | 效果 | 说明 |
| :--- | :--- | :--- |
| `cout <<"Hello."<< endl;` | 换行 | 立即刷新输出缓冲区 |
| `cout << "Hello.\n";` | 换行 | 不保证立即刷新 |
| `cout << "\n";` | 空行 | 效果一样 |
| `cout << endl;` | 空行 | 效果一样 |

**cout的特性：**
- 是`ostream`类的对象（定义在`iostream`中）
- 使用`<<`插入运算符
- 能够自动识别数据类型（智能对象）
### 1.2.3：cin输入
**基本用法：**
```cpp
int carrots;
cin >> carrots;     //从键盘读取整数
```
**cin的特性：**
- 是`istream`类的对象
- 使用`>>`抽取运算符
- 自动将输入字符转换为目标变量类型
- 信息从cin流向变量（`cin >> carrots`）

**❗关于cin/cout概念上的一些理解**
- 输出是一种流，`cout`对象表示这种流，`<<`（插入运算符）是`cout`对象的一个属性，它将字符串插入到输出流中（表现为程序显示一条信息）。
- 输入是一种流，`cin`对象表示这种流，`>>`是`cin`对象的一个属性，它从输入流中抽取字符到变量中。
- 符号`<<`、`>>`被选择用来指示信息流的方向。

## 1.3：变量、声明语句与赋值

### 1.3.1：声明语句
```cpp
int carrots;     //声明：告诉编译器需要一个int类型的内存空间，名为carrots
```
**声明语句提供的信息：**
1. 需要的内存大小（`int`类型）
2. 内存单元的名称（`carrots`）

**为什么变量必须声明**
- 防止因拼写错误而意外创建新变量（如BASIC中的问题）
- 编译器能捕获使用未声明变量的错误

**声明位置：**
- C++允许在首次使用变量前声明（C通常在函数开头）
- 推荐：尽可能在首次使用前声明
### 1.3.2：赋值语句
```cpp
//赋值运算符（=）
carrots = 25;     //将25赋值给carrots
carrots = carrots - 1;     //先计算carrots - 1, 再赋值给carrots
a = b = c = d = 25;     //可连续赋值（从右向左执行）
```
### 1.3.3：初始化
```cpp
double side = sqrt(area);     //声明的同时赋值
int count = 0;     //声明时初始化为0
```
### 1.3.4：cout输出变量
```cpp
cout << 25;     //整数25被存储为数值，即将25存储为二进制数，占4个字节，整数输出，25 + 10 = 35
cout << "25";     //程序在内部存储的是字符2和字符5的编码（ASCII/UTF-8字符），占3个字节（含\0），逐个字符输出，"25" + 10 = 指针偏移（无意义）
```

## 1.4：函数的定义、声明与调用

### 1.4.1：函数的基本格式
```cpp
type functionName(parameterList)     //函数头
{                                    //函数体开始
    statements                       //语句
    return value;                    //返回语句（有返回值时需要）
}                                    //函数体结束
```
### 1.4.2：函数原型
**作用：** 
在使用函数之前告诉编译器函数的接口信息（返回类型、参数类型、参数数量）
```cpp
double sqrt(double);     //原型：返回double，接受一个double参数
void simon(int);         //原型：无返回值，接受一个int参数
int function01(int, int) //原型：返回int，接受两个int参数
```
**原型和定义的区别：**
| 项目 | 函数原型 | 函数定义 |
| :--- | :--- | :--- |
| 内容 | 只有接口声明 | 包含完整代码 |
| 结尾 | 分号 `; `| 花括号 `{}` |
| 位置 | 通常放在 `main` 之前 | 通常放在 `main` 之后 |

**提供原型的两种方式：**
1. 手动在源代码中输入原型
2. 包含头文件（如`#include <math>`提供`sqrt()`的原型）———— 推荐
### 1.4.3：函数的分类
| 类型 | 返回值 | 示例 |
| :--- | :--- | :--- |
| 有返回值 | 返回一个值 | `sqrt(9)` 返回 3.0 |
| 无返回值 (void) | 不返回值 | `simon(3)` 只执行操作 |
- **有返回值的函数示例**
```cpp
#include <iostream>
#include <cmath>           // 提供sqrt()的原型

int stonetolb(int);        // 自定义函数原型

int main()
{
    using namespace std;
    
    double area;
    cin >> area;
    double side = sqrt(area);    // 调用库函数sqrt()
    
    int stone;
    cin >> stone;
    int pounds = stonetolb(stone); // 调用自定义函数
    cout << pounds << endl;
    
    return 0;
}

int stonetolb(int sts)      // 函数定义
{
    return 14 * sts;        // 返回计算结果
}
```
- **无返回值的函数示例**
```cpp
#include <iostream>
void simon(int);            // 原型：void表示无返回值

int main()
{
    using namespace std;
    simon(3);               // 函数调用（不能用在赋值中）
    return 0;
}

void simon(int n)           // 定义：void表示无返回值
{
    using namespace std;
    cout << "Simon says touch your toes " << n << " times." << endl;
    // void函数可以没有return，或写 return;
}
```
**重要规则：**
- void函数不能用于赋值语句：`x = simon(3);`❌
- 函数调用的括号不能省略，即使无参数：`rand()`✔️
### 1.4.4：多函数程序中的using编译指令
```cpp
// 方式1：放在所有函数之前（影响全局）
#include <iostream>
using namespace std;     // 所有函数都能用std中的名称

void simon(int);

int main() { /* 可用cout */ }
void simon(int n) { /* 可用cout */ }
```
```cpp
// 方式2：仅在需要的函数中放置（推荐）
#include <iostream>

void simon(int);

int main() {
    using namespace std;     // 仅main可用cout
    cout << "Hello";
    return 0;
}

void simon(int n) {
    // 这里不能直接使用cout，需加std::cout或using
    std::cout << n << endl;     // 使用std::前缀
}
```

# 本章关键术语速查
| 术语 | 含义 |
| :--- | :--- |
| 语句 (statement) | C++中完整的指令，以分号结束 |
| 标记 (token) | 一行代码中不可分割的最小元素 |
| 空白 (white space) | 空格、制表符、换行符的总称 |
| 变量 (variable) | 存储数据的内存单元的名称，值可修改 |
| 声明语句 | 定义变量的名称和类型 |
| 赋值语句 | 使用 = 给变量赋值 |
| 初始化 | 声明变量时同时赋初始值 |
| 函数原型 | 描述函数的接口（返回类型和参数类型），以分号结尾 |
| 函数定义 | 包含函数完整代码的实现，以花括号结尾 |
| 类 (class) | 用户自定义的数据类型，包含数据和操作 |
| 对象 (object) | 根据类创建的实体（类的实例） |
| 参数 (argument) | 传递给函数的信息 |
| 返回值 (return value) | 函数返回给调用者的值 |
| 预处理器 | 编译前处理 # 指令的程序 |
