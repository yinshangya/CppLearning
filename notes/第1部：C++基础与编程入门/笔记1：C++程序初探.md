## 1.1：C++程序的基本结构（main函数、预处理器、头文件）

### 1.1.1：最简单的C++程序
```cpp
#include <iostream>
int main()
{
    using namespace std;
    cout << "Hello World !" << endl;
    return 0;
}
```
### 1.1.2：程序的基本结构模块
```cpp
#include <iostream>    //预处理器指令
int main()             //函数头
{                      //函数定义开始
    //语句
    return 0;          //返回语句
}                      //函数定义结束
```
### 1.1.3：main()函数
| 要点 | 说明 |
| :--- | :--- |
| 必须存在 | C++程序必须包含一个名为`main()`的函数 |
| 程序入口 | 程序从`mian()`开始执行 |
| 大小写敏感 | 必须是`main` |
| 标准格式 | `int main()`（推荐），`int main(void)`也可 |
| 返回值 | 返回`int`值给操作系统，0通常表示成功，非0为失败 |
| 隐式返回 | 可省略`return 0`; 编译器会隐式添加（仅适用于`main`） |
| 不推荐 | `void main()`是非标准写法，某些系统不支持 |
### 1.1.4：预处理器（#include）
- 预处理器在编译之前处理以#开头的编译指令
- `#include <iostream>`将`iostream`头文件的内容替换到该位置
- 原始代码文件没有被改变，而是生成一个组合文件供编译器处理
### 1.1.5：头文件
**头文件命名约定**
| 头文件类型 | 命名约定 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| C++旧式 | 以 .h 结尾 | iostream.h | C++ |
| C旧式 | 以 .h 结尾 | math.h | C/C++ |
| C++新式 | 无扩展名 | iostream | C++，支持名称空间 |
| 转换后的C | 前缀c，无扩展名 | cmath | C++，支持名称空间 |

**要点：**
- 使用`cin`/`cout`必须包含 `#include <iostream>`
- 新式头文件（无`.h`）将定义放在`std`空间中

## 1.2：名称空间与cout输出/cin输入

### 1.2.1：名称空间（namespace）
**为什么需要名称空间：**
- 解决大型程序中的命令冲突
- 不同厂商的代码可能使用相同的函数名
- 例如：`Microflop::wanda()`和`Piscine::wanda()`可以同时存在
**std名称空间：**
- C++标准库的所有定义（`cout`、`cin`、`endl`等）都位于`std`名称空间中
- 新式头文件（无`.h`）才使用名称空间
**访问std的四种方式：**
```cpp
//方式1：全部引入（简单，适合小项目）
using namespace std;

//方式2：仅在有需求的函数中引入
void func()
{
    using namespace std;
    cout << "Hello" << endl; 
}

//方式3：只引入特定元素（推荐）
using std::cout;
using std::endl;
using std::cin;

//方式4：每次使用std::前缀（最明确）
std::cout << "Hello" << std::endl;
```
### 1.2.2：cout输出
**基本用法：**
```cpp
cout << "Hello World!";     //输出字符串
cout << endl;               //换行并刷新缓冲区
```
**拼接输出：**
```cpp
//多条语句拼接
cout << "Now you have" << "carrots." << endl;

//同一语句分多行（C++自由格式）
cout << "Now you have "
     << carrots
     << " carrots."
     << endl;
```
**endl与\n的区别**  
| 写法 | 效果 | 说明 |
| :--- | :--- | :--- |
| `cout <<"Hello."<< endl;` | 换行 | 立即刷新输出缓冲区 |
| `cout << "Hello.\n";` | 换行 | 不保证立即刷新 |
| `cout << "\n";` | 空行 | 效果一样 |
| `cout << endl;` | 空行 | 效果一样 |

**cout的特性：**
- 是`ostream`类的对象（定义在`iostream`中）
- 使用`<<`插入运算符
- 能够自动识别数据类型（智能对象）
